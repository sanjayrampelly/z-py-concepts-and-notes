Trying to modify an element inside an immutable tuple
→ not allowed

✔️ t = tuple(l)

Creating a new tuple and assigning it to variable t
→ allowed

Tuples are immutable, but variables pointing to tuples are not immutable.
You can always make a new tuple and reassign the variable.

***
t = ("apple", {1: "a", 2: "b"})

the second element is a dictionary, and dictionaries are mutable.

However, your next line:

t[1] = {3: "c"}

will raise an error:

TypeError: 'tuple' object does not support item assignment

because tuples themselves are immutable. You cannot replace any element of a tuple after it is created.

What you can do is modify the dictionary that is stored inside the tuple:

t = ("apple", {1: "a", 2: "b"})

t[1][3] = "c"      # modify the dictionary
print(t)

Output:

('apple', {1: 'a', 2: 'b', 3: 'c'})

This works because:

The tuple's structure remains unchanged (it still has the same two elements).
The dictionary object inside the tuple is mutable, so its contents can change.

lst = [[1,2,3], [4,5], [6,7,8],10]

def flatlist(lst):
    res=[]
    for i in lst:
        if isinstance(i,list):
            res.extend(flatlist(i))
            
        else:
            res.append(i)
            
    return res
    
print(flatlist(lst))



iterative way

def flatlist_iter(lst):
    res = []
    stack = lst[::-1]  # reverse to process left-to-right using pop

    while stack:
        item = stack.pop()
        if isinstance(item, list):
            stack.extend(item[::-1])  # reverse sublist before extending
        else:
            res.append(item)
    
    return res

# Example
lst = [1, [2, [3, 4], 5], [6, 7], 8]
print(flatlist_iter(lst))

def flatten(d, parent_key='', sep='_'):
    items = {}

    for k, v in d.items():
        new_key = f"{parent_key}{sep}{k}" if parent_key else k

        if isinstance(v, dict):
            items.update(flatten(v, new_key, sep))

        elif isinstance(v, list):
            for i, item in enumerate(v):
                list_key = f"{new_key}_{i}"
                # if isinstance(item, dict):
                #     items.update(flatten(item, list_key, sep))
                # else:
                items[list_key] = item

        else:
            items[new_key] = v

    return items
